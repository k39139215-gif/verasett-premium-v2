# Geist font asset

- Family: Geist Variable, normal style, weight axis 100–900, Latin subset.
- Local CSS family: `Verasett Geist` (namespaced to avoid host collisions).
- Source package: `@fontsource-variable/geist` version 5.3.0, npm metadata checked October 10, 2026.
- Original file: `files/geist-latin-wght-normal.woff2`.
- Included file: `Geist-Latin-Variable.woff2`, 29,400 bytes.
- License: SIL Open Font License 1.1. Preserve `OFL.txt` when copying the font.

The font is self-hosted by the consuming build. No remote font request or added runtime library is required. Suisse Intl is not bundled; a host that has a licensed webfont can supply it through `--va-font`.
